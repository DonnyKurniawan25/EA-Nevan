# Batasan yang diketahui

1. **Unit/kompilasi lulus, safety lengkap belum lulus.** Build 1.101: 0 error/0 warning, 1.036 checks runtime MQL dan 40.046 assertions native. Enam tes perbandingan dan satu regresi default telah dijalankan. Fault injection dan seluruh gate runtime belum lulus.
2. **Strategi belum konsisten menghasilkan profit.** Enam backtest real-tick lintas tiga interval tersedia pada reports/IMPROVEMENT_RESULTS.md. Kandidat H1/pullback tidak dipromosikan. Akun demo pernah menjalankan satu SELL yang selesai rugi US$16,28 virtual; entry sekarang diparkir OFF.
3. **Phase 2 belum lengkap.** Ada batas realized trading loss harian/mingguan, loss streak net dan cap entry dari history. Belum ada floating daily/weekly peak drawdown latch, cashflow-adjusted reference, recovery broker lengkap, Telegram atau fault injection.
4. **Satu posisi hedging saja.** Grid, multi-position basket, netting, basket-money TP dan penutupan multi-ticket belum didukung. Posisi ganda atau magic/comment collision memblokir entry dan memerlukan operator; tidak melakukan liquidation spekulatif terhadap posisi yang ambigu.
5. **SHADOW/DRY_RUN tidak mengirim request trading sama sekali.** Ketika dipilih saat posisi lama masih ada, EA hanya memantau; SL/TP server tetap menjadi pengaman. Jangan mengganti ke SHADOW sambil mengharapkan virtual emergency close.
6. **Real trading tidak tersedia dalam build ini**, walaupun `AllowRealTrading` diubah. Akun real hedging hanya dapat dimonitor dengan SHADOW/DRY_RUN; RULES_DEMO menolak init pada real.
7. **Persistence belum production-grade.** Global Variables + sentinel + file lock hanya untuk satu terminal. Jangan jalankan identitas sama pada terminal/VPS lain. Menghapus state atau memodifikasi F3 dapat menghapus pengaman; tidak ada auto-reset/remote resume.
8. **Entry outcome ambigu berhenti secara konservatif.** Broker yang memodifikasi comment, fill yang langsung SL/TP sebelum sempat diamati, reject/timeout setelah intent, atau partial state dapat memerlukan review manual meskipun tidak ada posisi tersisa. Tidak ada retry entry otomatis.
9. **Akuntansi terbatas pada deal history yang tersedia.** Limit entry menjumlah profit, commission, swap dan fee yang dibukukan; charges negatif lain diperhitungkan konservatif. Floating panel tetap profit+swap, tanpa komisi. Buffer sebelum entry tetap estimasi. Rekonsiliasi biaya/cashflow broker yang kompleks dan basket belum tersertifikasi.
10. **Equity reference** adalah equity saat state pertama dibuat, persisten sampai review/reset manual. Bukan high-water mark, daily/weekly anchor, atau cashflow-adjusted reference. Deposit/withdrawal perlu review ulang.
11. **Risk-to-stop bukan maximum loss terjamin.** Gap/slippage, likuiditas, market closed, broker stop-out dan kegagalan koneksi bisa melampaui estimasi. Close retry dibatasi tiga kali dengan jeda 10 detik, lalu memerlukan operator. Berjalannya timer tidak menjamin tersedianya broker.
12. **Filter H1 eksperimen tersedia tetapi belum disetujui untuk entry.** Default baseline satu timeframe. ONNX, LLM, berita, DST/session internasional otomatis dan Telegram belum tersedia. Filter sesi tetap memakai waktu server broker.
13. **SHADOW baru mencatat sinyal aturan**; belum ada label outcome/model evaluation/parity statistik. Startup READY bukan bukti telah selesai evaluasi G6 jangka panjang.
14. **Kalibrasi default wajib.** `CostBufferPerLot`, spread points, account currency USC/USD, lot/contract size dan margin berbeda menurut broker. Raw summed lots adalah cap tambahan, bukan penyamaan notional lintas simbol.
15. **Audit/state runtime failure** memblokir entry baru. Pengelolaan exit dasar tetap dicoba pada mode demo opt-in selama ownership jelas; jika rekonsiliasi ambigu, EA meminta operator dan mengandalkan stop broker yang sudah dikirim.

Pekerjaan berikutnya: validasi strategi yang lebih luas serta fault injection broker/recovery. Hasil yang masih merugi tidak menjadi dasar promosi ke transaksi otomatis.
